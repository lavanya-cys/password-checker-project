# 🔐 Password Strength Checker

A modern web-based Password Strength Checker built using HTML, CSS, and JavaScript.

**Live** [click here] (https://lavanya-cys.github.io/password-checker-project/)

## 🚀 Features
- Real-time password analysis
- Strength percentage meter
- Password generator
- Show/Hide password
- Crack time estimation
- Interactive UI/UX
- Cybersecurity themed design

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Purpose
This project helps users create secure passwords and understand password security concepts.
